##C - Variables, if, else, while
##Description
Introduction to variables, conditional statements (if, else if, else), and loops in C programming.

##Tasks
0-positive_or_negative.c
A program that generates a random number and prints whether it is positive, negative, or zero.

1-last_digit.c
Generates a random number and uses the modulo operator (%) to extract its last digit.

2-print_alphabet.c
Prints the alphabet in lowercase, followed by a new line.

3-print_alphabets.c
Prints the alphabet in lowercase, and then in uppercase, followed by a new line.

4-print_alphabt.c
Prints the alphabet in lowercase, followed by a new line and skip q and e.

5-print_numbers.c
Prints all single digit numbers of base 10 starting from 0, followed by a new line.
